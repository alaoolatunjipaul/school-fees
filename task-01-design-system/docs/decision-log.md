- Typeface: Noto Sans. Reasons: wide glyph coverage for Yoruba names with marked letters, the naira sign displays correctly (tested in Figma), Android uses Noto-family fallbacks if a font fails to load, and it is neutral and readable. Cost: it is generic, so I will differentiate with my own weights and letter spacing. Rejected DM Sans because it is the class example font.
- Type scale: all 15 line heights set to font size x 1.4 (display, headline), x 1.5 (title, body), x 1.6 (label). Body and label fonts changed from the plugin default Roboto to Noto Sans so the app loads one family. Display large letter spacing changed from the default -0.25px to -0.57px (1% of 57px), judged by eye against the default.
